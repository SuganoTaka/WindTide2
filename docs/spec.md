# 潮見帖フォーキャスト — 仕様書（案）

漁港を選ぶと、**風予報とタイドグラフを週間・月間単位で出力**できる Web アプリ。
既存の「潮見帖」（全国3,925港の釣り情報マップ）から、**予報の出力機能に特化**して作り直す。

- 版: 0.1（ドラフト）
- 作成: 2026-11-19
- 元アプリ: 潮見帖（`SuganoTaka/FishingPortJapan`）

---

## 1. 目的とスコープ

### やること
- 漁港を選び、**風（風向・風速・突風）** と **潮位（タイドグラフ・満干潮・潮回り）** を確認する
- **週間（7日）** と **月間（30日）** の2つの時間軸で見る
- 見た内容を **CSV（Excel）／PDF（印刷）** で持ち出せる

### やらないこと
- 船釣りの釣果、魚種データの管理（潮見帖側の役割）
- ルート案内・距離計算（潮見帖側の役割）
- ユーザー登録・ログイン（初期版はローカル保存のみ）

---

## 2. 利用シーン

| シーン | 必要なもの |
| --- | --- |
| 週末の釣行計画（3日前） | 風速・風向の時間推移、潮の動き（満干時刻） |
| 大潮・小潮の当たりを月間で探す | 30日の潮回りカレンダー |
| 当日の朝マズメ判断 | 日の出・日の入り、風速、潮位 |
| 仲間への共有 | URL共有、PDF/CSVの書き出し |

## 3. 機能要件

### 3.1 港の選択
- 全国 3,925 港（漁港 2,931 / 港湾 994）から選択
- 検索（港名・都道府県）、都道府県・種別での絞り込み
- 「現在地から近い順」ソート（Geolocation API）
- お気に入り・最近見た港（localStorage）
- 選択中の港は URL に反映（`?port=H00012&view=week`）→ 共有可能

### 3.2 週間ビュー（7日）
- **風**: 7日×24時間のヒートマップ（風速を色で表現）＋各セルに風向矢印、時刻軸は3時間刻み表示
- **日別サマリ**: 日付・曜日・天気アイコン・最大風速・最多風向・最大突風・日の出/日の入り
- **潮位**: 168時間のタイドグラフ（満潮・干潮マーカー、現在時刻線、潮回り、月齢）
- しきい値超過（例: 10m/s以上）は警告色でハイライト

### 3.3 月間ビュー（30日）
- **カレンダー形式**（7列）: 各日に「潮回り（大潮/中潮/小潮/長潮/若潮）」「満潮・干潮の時刻（最大4つ）」「日別最大風速と風向」
- **予報の限界を明示**: 16日目以降は風が取得できないため、セルに「予報範囲外」を表示（空白にしない）
- **潮位曲線**は 16 日分まで。17日目以降の満干時刻は「概算」ラベル付きで表示
- 月の切り替え（前月/翌月）、今日へのジャンプ

### 3.4 出力
| 形式 | 内容 | 仕様 |
| --- | --- | --- |
| CSV（時間別） | 日時・気温・風速・風向（16方位＋度）・突風・降水量・降水確率・波高・潮位 | UTF-8 BOM付き（Excelで文字化けしない）、ファイル名 `wind-tide_{港名}_{開始日}.csv` |
| CSV（日別） | 日付・潮回り・満潮時刻/潮位・干潮時刻/潮位・最大風速・最多風向・最大突風・日の出/日の入り | 同上 |
| PDF / 印刷 | 週間・月間それぞれ A4横 1ページに収める印刷用レイアウト | `window.print()` + 印刷用CSS。ヘッダに港名・期間・出典、フッタに生成日時 |
| 共有URL | 港・表示期間・ビューを含むURL | クエリパラメータのみ（サーバー保存なし） |

### 3.5 免責・出典表示
- 「潮位・気象はモデル推算値であり、実際の海況と異なる場合があります」
- 出典: 気象データ Open-Meteo / 地図 国土地理院 / 港データ 国土数値情報（国土交通省）

---

### 3.6 公式情報の併記（気象庁）

Open-Meteo の時系列とは別に、**気象庁の公式情報**を港ページに併記する。

- **週間天気（気象庁）**: 7日分の天気・降水確率・最高/最低気温。Open-Meteo の数値と並べる
- **海上予報**: その港が属する**海上予報区**の「風向・風速・天気・視程・波高」（24時間先まで）
- **海上警報・注意報**: 発表中の場合は赤帯で警告（例:「海上強風警報」）
- 取得できない場合は**ブロックごと非表示**（Open-Meteo の表示は継続）

表示位置は「港ヘッダ」直下の**公式情報カード**とし、時系列グラフより上に置く（判断材料として優先度が高いため）。

## 4. データ仕様

### 4.1 外部API（2026-11-19 時点の実測）

| API | 用途 | 上限 | 備考 |
| --- | --- | --- | --- |
| `api.open-meteo.com/v1/forecast` | 風・気温・降水・日の出/入 | **16日**（`forecast_days=16` で384時間） | 30日指定は400 |
| `marine-api.open-meteo.com/v1/marine` | 潮位・波高・水温 | **16日**（同上） | 30日指定は400 |
| Open-Meteo Archive API | 平年値（任意・将来） | 過去データ | 月間の「平年並み」表示に利用可 |
| 気象庁 府県天気予報・週間天気 | 公式の短期予報 | 3日／7日 | `www.jma.go.jp/bosai/forecast/data/forecast/{府県}.json`（非公式JSON・補助） |
| 気象庁 防災情報XML（地方海上予報 H28） | 沿岸の風・波・視程 | 24時間 | `data.jma.go.jp/developer/xml/feed/other.xml` から取得 |
| 気象庁 防災情報XML（地方海上警報・全般海上警報） | 安全情報 | 随時 | 同上 |
| 気象庁 潮位情報 | 高潮・潮位注意 | 随時 | 同上（**潮位の推算値そのものはAPI非提供**） |

- `timezone=Asia/Tokyo`、`wind_speed_unit=ms`、`cell_selection=sea`（海洋）
- 取得は**サーバー側で15分キャッシュ**。サーバーが外部に出られない環境では**ブラウザから直接取得**にフォールバック（潮見帖で実装済みの方式を踏襲）

### 4.2 内部データモデル

```ts
type HourPoint = {
  t: string;            // "2026-11-20T13:00" (JST)
  wind: number | null;  // m/s
  windDir: number | null; // 度（風が吹いてくる向き）
  gust: number | null;
  temp: number | null;
  precip: number | null;
  precipProb: number | null;
  wave: number | null;
  seaLevel: number | null; // m (MSL)
};

type DaySummary = {
  date: string;                 // "2026-11-20"
  tideName: string;             // 大潮/中潮/小潮/長潮/若潮
  moonAge: number;
  highs: { t: string; h: number }[];
  lows: { t: string; h: number }[];
  maxWind: number | null;
  dominantWindDir: number | null;
  maxGust: number | null;
  sunrise: string | null;
  sunset: string | null;
  inForecastRange: boolean;     // false = 16日超（概算/範囲外）
  estimated: boolean;           // true = 満干時刻が概算
};
```

### 4.3 潮汐の計算ルール（潮見帖から流用）
- 満潮・干潮: 1時間値の極値＋3点放物線補間で ±10分程度に丸める
- 潮回り: 月齢から判定（0〜2 大潮 / 3〜7 中潮 / 8〜10 小潮 / 11〜13 中潮 / 14〜16 大潮 / 17〜20 中潮 / 21〜24 小潮 / 25〜26 長潮 / 27〜28 若潮 / 29 中潮）
- 月齢: 朔（2000-01-06 18:14 UTC）からの経過日数 mod 29.530588853
- 17日目以降の満干時刻（任意実装）: 直近の極値間隔の平均から外挿し「概算」と明示

### 4.4 CSV 列定義（時間別）
`日時, 気温(℃), 風速(m/s), 風向, 風向(度), 突風(m/s), 降水量(mm), 降水確率(%), 波高(m), 潮位(m)`

### 4.5 CSV 列定義（日別）
`日付, 曜日, 潮回り, 満潮1, 潮位1, 満潮2, 潮位2, 干潮1, 潮位1, 干潮2, 潮位2, 最大風速, 最多風向, 最大突風, 日の出, 日の入り`

---

### 4.6 気象庁データの取り扱い

| 項目 | 仕様 |
| --- | --- |
| 取得方法 | サーバー側で取得（CORS のためブラウザ直取得は不可） |
| 本線 | 防災情報XML（`data.jma.go.jp/developer/xml/feed/other.xml` → 各電文XML） |
| 補助 | `www.jma.go.jp/bosai/forecast/data/forecast/{府県コード}.json`（非公式・変更リスクあり） |
| キャッシュ | 海上予報・週間天気は **30分**、警報系は **5分** |
| 文字コード | XML は UTF-8。数値は全角数字やノット表記が混在するため正規化して扱う（例: `３０ノット（１５メートル）` → 15 m/s） |
| 区域マッピング | 港（3,925件）に **府県予報区コード** と **海上予報区名** を持たせる。府県は都道府県コードから機械的に割当、海上予報区は最寄り海域（約60）を港の座標から割当 |
| 障害時 | XMLが取れない場合は併記ブロックを非表示にし、Open-Meteo の表示は維持 |
| 規約 | 政府標準利用規約。出典「気象庁」を明記。フィードは定期取得を前提に、過度なアクセスをしない |

**数値の優先順位**: 時系列グラフ・潮位・CSV出力は Open-Meteo、文章としての公式予報・警報は気象庁を正とする（画面にどちらの値か明記する）。

## 6. 非機能要件

- **性能**: 初回表示 2.5秒以内（港データ 750KB は gzip 配信＋キャッシュヘッダ）
- **API 節約**: サーバー15分キャッシュ、同一港の再取得を抑止、`AbortController` で中断
- **タイムゾーン**: 表示はすべて JST。サーバー・ブラウザで計算結果が一致すること
- **アクセシビリティ**: キーボード操作、コントラスト比 4.5:1、色だけに依存しない（風速は数値も併記）
- **印刷**: A4横・白背景・ページ分割制御（`@media print`）
- **対応ブラウザ**: Chrome / Edge / Safari 最新、iOS Safari
- **外部障害時**: API 失敗時は「取得できませんでした」と理由を表示し、直前のキャッシュがあればそれを表示

## 9. リスクと対応

| リスク | 影響 | 対応 |
| --- | --- | --- |
| 潮位の予報が16日まで | 月間ビューの後半が空になる | 「予報範囲外」を明示＋満干は概算表示（タスク13） |
| Open-Meteo の無料枠 | アクセス増で制限 | サーバーキャッシュ15分、同一港の連打抑止 |
| 潮位はモデル推算 | 実際の潮位と差が出る | 画面に免責を明記。判断は海上保安庁の潮汐表で |
| 港数の多さ（3,925件） | 初回ロードが重い | 750KBをgzip＋キャッシュヘッダ、必要なら都道府県別に分割 |
| 気象庁のJSONが非公式 | 予告なく仕様変更 | 本線はXML電文。JSONは補助扱いにして失敗時は非表示 |
| 気象庁の数値表現（全角・ノット） | パース誤り | 正規化関数をユニットテストで担保（`３０ノット（１５メートル）`→15） |
| XMLフィードへの過剰アクセス | 遮断リスク | 30分キャッシュ＋サーバー側のみ。港ごとではなく区域単位で取得 |
